# 数字提示器（Android）

面向截图中的 7×7 动态数字关卡：读取手机屏幕，使用设备本地 ML Kit 识别数字，在目标格显示黄色边框。数字每次重排后会重新搜索。程序不会自动点击游戏。

## 安装

1. Android Studio 打开 `NumberHint` 文件夹，等待 Gradle 同步。需要 Android SDK 35、JDK 17 和可下载依赖的网络。
2. 连接 Android 8.0 或更新的手机，运行 `app`。项目没有预编译 APK。
3. 首次运行授权悬浮窗。点“开始识别”，在系统弹窗里选择**整个屏幕**并确认共享，然后返回游戏。
4. 屏幕上方的悬浮条显示当前要找的数字。黄色边框提示位置。点游戏数字后按悬浮条 `+`；误按用 `−`。`×` 停止截屏。
5. 若边框偏移或找不到数字，回应用按百分比修改棋盘外框。示例图片为左 15%、上 34%、右 85%、下 77%；不同分辨率或游戏布局需调整。尤其要让 7×7 棋盘完整落在框内。

## 限制

- OCR 受闪烁、颜色、字号和屏幕更新影响，可能漏识；黄色边框出现时也应看一眼数字再点。OCR 没识别到唯一目标时会隐藏边框。
- 该版本按 `+` 手动进入下一个数，不会自动判断是否点中。停止后重新启动目标从 1 开始。
- 仅支持竖屏且游戏棋盘基本保持在选定区域；系统选择“仅共享一个应用”或旋转屏幕可能导致截取尺寸不匹配。
- 悬浮圈可能被系统一并截入画面，通常不遮挡格子中央的数字。图像仅在手机内存中处理，不保存或上传。

## 不安装 Android Studio：通过 GitHub 自动生成 APK

需要一个 GitHub 账号，以及首次构建时能访问 GitHub 的网络。浏览器操作：

1. 在 GitHub 新建一个**私有**仓库，例如 `number-hint`。
2. 将本压缩包里 `NumberHint` 目录**内部所有文件**上传到仓库根目录，包括 `.github/workflows/build-apk.yml`。GitHub 网页上传隐藏的 `.github` 目录不便时，可在仓库的网页编辑器直接新建 `.github/workflows/build-apk.yml` 并粘贴该文件内容。
3. 打开仓库 **Actions → 生成安卓安装包 → Run workflow**。首次运行通常数分钟。
4. 工作流变绿后打开这次运行，在页面底部 **Artifacts** 下载 `NumberHint-APK`；解压得到 `app-debug.apk`，传到手机并安装。
5. 手机若提示“禁止安装未知应用”，在系统设置中允许此次使用的浏览器或文件管理器安装。安装后按前文步骤授权悬浮窗、全屏共享。

调试版 APK 适合自己使用；不要将屏幕识别权限授予来源不明的 APK。
